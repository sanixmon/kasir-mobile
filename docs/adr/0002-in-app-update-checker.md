# 2. In-App Update Checker via GitHub Releases Public API

Because the application is distributed via direct APK sideloading rather than the Google Play Store, end-users (cashiers and administrators) had no way of knowing when updates were published without manually browsing GitHub. We decided to implement an in-app update checker that queries the public GitHub Releases API (`api.github.com/repos/sanixmon/kasir-mobile/releases/latest`) on startup and via a manual button in Settings. When a newer SemVer release is detected, the app displays a non-blocking prompt dialog detailing the new version and release notes, with an action to download the APK directly via the Android system browser (`ACTION_VIEW`). Dismissing the prompt snoozes notifications for the remainder of the active application session.
